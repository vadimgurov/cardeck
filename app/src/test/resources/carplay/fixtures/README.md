# Приспособления для воспроизведения моделей автомобилей

Извлечено из реальных журналов работы (`*.jsonl`) `tools/extract_car_fixtures.py` для
`replay/BtLinkReplayTest`, `replay/TunnelReplayTest` выполняют регрессию между моделями: меняют определенную модель
После протокола записанные стимулы других моделей должны вызывать реакции, соответствующие записанным.

```bash
python3 tools/extract_car_fixtures.py ~/logs/cardeck -o app/src/test/resources/carplay/fixtures
./gradlew testStandardDebugUnitTest --tests '*Replay*'
```

**`*.jsonl` gitignore по умолчанию**: содержит реальные данные, такие как адрес Bluetooth автомобиля, имя точки доступа, открытый ключ сопряжения и т. д. Необходимо зарегистрироваться.
При использовании в качестве общедоступных образцов регрессии они проверяются один за другим, десенсибилизируются (SSID может быть псевдонимом; MAC участвует в проверке протокола и не может быть изменен), а затем игнорируются.
Оба теста автоматически пропускаются при отсутствии фикстуры (новые клоны не затрагиваются).

## Классификация утверждений (автоматически определяется во время извлечения, записывается в поле rxHasIdent каждого раунда)

- RAW сбрасывает бюджет старого значения 512Б/направление, часто обрезает идентификационный кадр (Audi 575B, Geely 489B); более скрытно
  Усечение объединит хвосты различных чтений в псевдокадры с «точно полной длиной» (контрольная сумма полезной нагрузки не удалась, и движок молчит).
  Отбросить — воспроизвести отладку фактических результатов измерений). Экстрактор проверяется кадр за кадром на основе одной и той же проверки механизма (сумма заголовка кадра/полезной нагрузки равна нулю).
  Все плохие кадры, начиная с первого, обрезаются и обозначаются `rxHasIdent`. Этот тип раунда выполняет только **утверждение канального уровня** (SYN/adopt session table/
  Распознавание запуска 0x1D00 должно соответствовать записи);
- Кадр распознавания сохраняется неповрежденным (`rxHasIdent=true`) → **Полное утверждение**: Должна быть выполнена запись отдельной последовательности CSM.
  Префикс заказа для воспроизведения;
- Туннельный уровень: последовательность записи должна быть **упорядоченной подпоследовательностью** воспроизведения (допускаются намеренно добавленные ответы, такие как пакеты MIB3,
  Запишите несколько ответов/не по порядку);
- Бюджет увеличен до 4096B (`Iap2LinkChannel.RAW_DUMP_LIMIT*`) - идентификация/MFi/учетные данные для новых журналов.
  Весь процесс может быть записан, и прибор автоматически обновляется до полного утверждения.

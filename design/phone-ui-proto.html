Идеи рефакторинга

  • Карта героя несет в себе единственный фокус：Визуализация статуса подключения + основная операция，Замените исходный разбросанный ряд кнопок
  • Список подготовки к подключению：Точка доступа / Bluetooth / Три разрешения звука，со статусным логотипом，Вы можете с первого взгляда сказать, чего не хватает
  • Свернуть отладочную информацию：Shell Глобальный статус и журналы по умолчанию закрыты.，Не мешает ежедневному использованию
  • Никаких удалений функций：Все оригинальные кнопки / переключатель / Все поля ввода сохраняются.，Реорганизовать только уровни
  • M3 система токенов：Прямое сопоставление переменных оттенка Android themes.xml，Удобно 1:1 восстановить

Android картографирование

  • карта → MaterialCardView（24dp закругленные углы）
  • переключатель → MaterialSwitch · главная кнопка → MaterialButton(pill)
  • Тема → Theme.Material3.Dark + Пользовательская цветовая палитра
  • Всплывающее окно → MaterialAlertDialogBuilder · Легкое напоминание → Snackbar
